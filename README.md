# Artificial-Intelligence-Study

## What is AI?
AI(Artificial-Intelligence-Study)는 말 그대로 "인공적인 지능" 인간이 만들었다는 전제 하에, 특정 문제에 대하여 스스로 학습하고, 계산이 가능한 기술을 AI라고 합니다.

## Background
최근 3차 산업혁명(정보화)을 뛰어넘는 4차 산업혁명(IoT, AI)이라는 키워드가 떠오르는 가운데, 그 중에서도 인공지능(AI)은 가장 큰 비중을 차지하고 있습니다.
따라서 이 저장소에서는 AI에 대한 지식과, AI에 대한 실험을 진행하고 있습니다.
